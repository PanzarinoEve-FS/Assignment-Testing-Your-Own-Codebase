Testing Your Own Codebase

Run each function by hand and see what it returns. Use the type selector to send something other than a string — a number, a boolean, null or undefined.

sumOfArray(arr)

Adds every number in an array. Non-numeric entries are skipped. Returns 0 for an empty or invalid input.

Comma separated. Quoted text stays a string: 1, "2", true, null, NaN


        


        
        

            
reverseString(str)

            
Reverses a string. Numbers are converted first, so 123 becomes
               "321" and -1 becomes "1-".


            

                
                
                
                
            


            

        


        
        

            
isPalindrome(str)

            
Checks whether a string reads the same both ways. Case, spaces
               and punctuation are ignored.


            

                
                
                
                
            


            

        


        
        

            
findMax(arr)

            
Finds the largest number in an array. Returns null
               when there is no number to return, so you can tell "no answer"
               apart from a real result of 0.

capitalizeWords(str)

            
Capitalizes the first letter of every word. Only the first
               letter changes, so "don't" stays "Don't".


            

                
                
                
                
            


            

        


        
        

            
countVowels(str)

            
Counts the vowels in a string. Case-insensitive, and "y" is not
               counted.

Returns a new array with duplicates removed, keeping the first
               occurrence of each and the original order.
